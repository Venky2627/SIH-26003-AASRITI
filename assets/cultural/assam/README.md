# Assam Cultural Asset Pack (SmritiSetu)
This directory contains cultural asset manifests, vector motifs, and regional object metadata for Assam:
- Traditional Foods: Jolpan, Pitha, Assam Milk Tea, Kaji Nemu, Joha Rice.
- Cultural Objects: Japi, Gamosa, Xorai, Dhol, Pepa.
- Market Haat Items: Local NER agricultural produce and handloom textiles.
