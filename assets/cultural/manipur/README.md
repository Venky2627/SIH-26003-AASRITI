# Manipur Cultural Asset Pack (SmritiSetu)
This directory contains cultural asset manifests and regional object metadata for Manipur:
- Traditional Foods: Chak-hao (Black Rice), Kangsoi, Singju.
- Cultural Objects: Pena, Radha-Krishna Pung, Meitei Pot, Traditional Phanek.
- Market Items: Khwairamband Bazar (Ima Keithel) goods.
