# Meghalaya Cultural Asset Pack (SmritiSetu)
This directory contains cultural asset manifests and regional object metadata for Meghalaya:
- Traditional Foods: Jadoh, Tungrymbai, Dohneiiong.
- Cultural Objects: Ryndia Silk Shawl, Khasi Traditional Bamboo Basket, Duitara.
- Market Items: Iewduh (Bara Bazar) goods.
